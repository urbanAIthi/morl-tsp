# ITSC 2026 Reproduction

This folder contains the compact reproduction pipeline for the ITSC 2026 paper:

> **Preference-Conditioned Multi-Objective Reinforcement Learning for Runtime-Tunable Transit Signal Priority**  
> Philip-Roman Adam and Stefanie Schmidtner

Run commands from the repository root.

## Rerun

Install the environment once:

```bash
uv sync
```

Optionally rerun hyperparameter tuning:

```bash
uv run slurm_experiment --yaml_path=ITSC_2026/configs/train/hpt/morl_nyc6698_optuna.yaml
uv run slurm_experiment --yaml_path=ITSC_2026/configs/train/hpt/ppo_nyc6698_optuna.yaml
```

Train the paper models:

```bash
uv run slurm_experiment --yaml_path=ITSC_2026/configs/train/morl/train_morl_itsc2026.yaml
uv run slurm_experiment --yaml_path=ITSC_2026/configs/train/ppo/train_ppo_itsc2026_chi2412.yaml
uv run slurm_experiment --yaml_path=ITSC_2026/configs/train/ppo/train_ppo_itsc2026_la2114.yaml
uv run slurm_experiment --yaml_path=ITSC_2026/configs/train/ppo/train_ppo_itsc2026_nyc10802.yaml
```

Evaluate the trained models:

```bash
uv run slurm_experiment --yaml_path=ITSC_2026/configs/eval/morl_rc4.yaml
uv run slurm_experiment --yaml_path=ITSC_2026/configs/eval/morl_iz_default.yaml
uv run slurm_experiment --yaml_path=ITSC_2026/configs/eval/ppo_rc4.yaml
```

If the evaluations ran on Slurm, copy the generated rows back before plotting:

```bash
rsync -a user@cluster.example.edu:/remote/path/to/morl_tsp/ITSC_2026/results/evaluations/ ITSC_2026/results/evaluations/
```

Generate paper artifacts:

```bash
uv run python ITSC_2026/src/plot_publication_figures.py
uv run python ITSC_2026/src/generate_publication_tables.py
```

Outputs are written to:

- `ITSC_2026/models/morl`
- `ITSC_2026/models/ppo`
- `ITSC_2026/results/evaluations`
- `ITSC_2026/results/figures`
- `ITSC_2026/results/tables`

## FAQ

### How do I run locally instead of on Slurm?

Add `--profile=local`:

```bash
uv run slurm_experiment --yaml_path=ITSC_2026/configs/eval/morl_rc4.yaml --profile=local
```

### How is the runner selected?

`slurm_experiment` reads the YAML. HPT YAMLs contain `hyperparameter_object`, eval YAMLs contain `eval`, and all other YAMLs are treated as training experiments.

### Where are Slurm resources configured?

Each YAML has a `slurm` section for requested compute. Machine-specific defaults live in `morl_tsp/experiment/slurm_profiles.yaml`.
For a new machine, start from `morl_tsp/experiment/slurm_profiles.yaml.example` and create a local `slurm_profiles.yaml`.

### Where do trained models go?

Training YAMLs set `model_output_dir`. MORL models are saved under `ITSC_2026/models/morl`; PPO models are saved under `ITSC_2026/models/ppo`.

### Where do evaluation CSVs go?

The eval YAML `eval.rows_root` controls this. Current paper rows are written below `ITSC_2026/results/evaluations`.

### Do evaluations include baselines?

Yes. Eval YAMLs set shared baselines in `eval.baselines`, currently `fixed_ts` and `tsp`. The eval runner expands each model experiment into model plus baseline evaluations.

### How do I enable or disable W&B?

Pass an environment override to the wrapper:

```bash
uv run slurm_experiment --yaml_path=ITSC_2026/configs/eval/morl_rc4.yaml --WANDB_MODE=online
uv run slurm_experiment --yaml_path=ITSC_2026/configs/eval/morl_rc4.yaml --WANDB_MODE=offline
```

For online logging, run `wandb login` once on the machine that executes the job. For public reruns, `WANDB_MODE=offline` is the safest default.

### What does hyperparameter tuning optimize?

The HPT configs optimize the training objective logged by the training run. They do not run the full paper evaluation loop for each trial, so final model comparison still comes from the eval YAMLs.

### Which values are paper-specific constants?

The plotting and table scripts hard-code paper presentation choices such as free-flow delay baselines, axis bounds, selected case-study cities, selected weights, and static feature-correlation values. These are not learned from the eval CSVs.

### How do I get Slurm outputs back locally?

The wrapper syncs code to Slurm before submission. It intentionally does not copy large artifacts back automatically. After jobs finish, use `rsync` for `ITSC_2026/results/evaluations` and, if needed, `ITSC_2026/models`.

### Which files define the paper experiments?

Training configs are in `ITSC_2026/configs/train`. Evaluation configs are in `ITSC_2026/configs/eval`.

### Which scripts create the final paper outputs?

Figures are generated by `ITSC_2026/src/plot_publication_figures.py`. Tables are generated by `ITSC_2026/src/generate_publication_tables.py`.
